# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Dune: Awakening private dedicated-server owners and trusted remote administrators use DST to operate and support a self-hosted server from a Windows desktop shell or browser portal.

## Product Purpose

DST makes routine server operation, configuration, diagnostics, and gameplay administration understandable and safer without requiring operators to assemble the underlying PowerShell, VM, database, and game-server workflows themselves.

## Operating Context

DST ships as one Windows installer containing a PowerShell HTTP backend, React portal, and WebView2 desktop shell. The same portal supports local owners and permission-limited remote viewers.

## Capabilities and Constraints

Permissions and platform capability checks remain authoritative. Browser-local preferences are intentionally scoped to each browser profile and origin. Preview visualization must be distinguished from live-derived status and cache observations, and must not be presented as live telemetry. Public supporter credits are centralized on the Sponsors & Credits route, with the optional Buy Me a Coffee action kept page-local; Hawk_I5's established main-banner recognition remains separate.

## Brand Commitments

The established dark Dune interface uses warm desert neutrals, amber actions, Eyes of Ibad cyan focus states, concise operational language, and familiar Windows administration patterns.

## Evidence on Hand

Repository code, tests, documentation, and shipped assets are the source of truth. Sponsor names or product claims must not be invented.

## Product Principles

- Make system state and data provenance explicit.
- Preserve user control and safe operational defaults.
- Keep navigation discoverable across local and remote contexts.
- Extend the incumbent visual system rather than introducing isolated visual worlds.

## Accessibility & Inclusion

Interactive controls support keyboard use, visible focus, semantic labels, responsive layouts, and touch-sized targets.
